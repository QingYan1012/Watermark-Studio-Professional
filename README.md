# 水印标注工坊（Watermark Studio）

面向岩心箱/探槽照片标注场景做的批量水印工具：底图色块/图标 + 可编辑文字 +
阴影效果 + 本地字体，支持按 Excel/CSV 表格批量填充文字、自由拖拽定位、
批量导出并按规则重命名。

## 1. 运行（开发调试）

```bash
pip install -r requirements.txt
python main.py
```

## 2. 打包成 Windows 桌面 exe

把 `fonts/` 目录换成你想内置的字体文件（可选，不放也没关系，程序会自动
读取系统已安装的字体），然后双击运行（或在命令行执行）：

```
build.bat
```

打包完成后，`dist\WatermarkStudio.exe` 就是可以直接分发使用的单文件程序。

## 3. 基本操作流程

1. **打开图片**：工具栏「打开图片」选多张，或「打开文件夹」整目录导入。
2. **编辑模板**：右侧「元素列表」默认有一个色块图标 + 一段带阴影的文字
   （对应你截图3的效果）。点选元素后，右侧属性面板可以改：
   - 文字：内容（支持 `{矿名}` `{箱数}` 这类占位符）、字体（下拉框里是你
     电脑上装的所有字体）、字号、颜色、加粗、阴影颜色/偏移/模糊/不透明度。
   - 图标：图片路径（换成任意 PNG，比如你自己的色块图或 logo）、宽高比例、
     不透明度。
   - 位置：直接在中间画布上按住元素拖动即可；也可以在属性面板里输入精确的
     0~1 相对坐标。
3. **导入批量数据**：工具栏「导入数据表」选一个 Excel/CSV。表格每一行是
   一张照片要填的数据（比如：矿名、钻孔编号、箱数、孔深起、孔深止……）。
   - 如果表格里有一列是"文件名"，导入时选它作为匹配列，程序会按文件名
     （不含扩展名）把每一行对应到相应照片；
   - 不选的话就按表格行顺序对应到图片列表顺序。
   - 导入后仍可以在左侧「编辑当前图片数据…」里对单张照片手动微调。
4. **导出**：
   - 「导出当前图片」：单独存一张。
   - 「批量导出全部」：按底部「导出文件名规则」（同样支持 `{字段名}` 占位符，
     比如 `{矿名}_{钻孔编号}_{箱数}箱`）批量重命名并导出到选定目录，重名会
     自动加序号避免覆盖。
5. **保存/加载模板**：调好一套排版（色块位置、字体字号、阴影参数）后用
   「保存模板」存成 `.json`，下次「加载模板」秒还原，不用重新摆位置。

## 4. 目录结构

```
watermark_studio/
├── main.py           # 入口
├── ui.py             # 主界面（画布拖拽、属性面板、批量导入导出）
├── model.py           # 模板/元素数据结构，JSON 序列化
├── renderer.py        # 把元素画到图片上（含阴影、占位符替换）
├── font_manager.py    # 扫描本地系统字体
├── data_import.py     # 读取 Excel/CSV 并与图片匹配
├── fonts/              # 可选：放你想内置打包的字体文件
├── requirements.txt
└── build.bat           # 一键打包 exe
```

## 5. 本次更新（对照反馈逐条修改）

- **字体下拉**：改成"输入框+悬浮列表"的可搜索下拉框，打字直接过滤，也支持鼠标滚轮滚动，不用再一项项点。
- **UI 自适应分辨率**：启动时按屏幕分辨率算窗口大小并居中，不再是写死的 1400x860；侧边栏宽度也会按窗口宽度略微调整。
- **预览框自动居中 + 适应窗口**：不再固定 860px 宽，而是按画布实际可用空间自动缩放并居中显示；窗口大小变化时自动重新适配。
- **预览区右键菜单**：右键点到元素上可以"复制/置顶/置底/上移/下移/删除"；右键空白处可以"适应窗口大小"或"在此新增文字/图标元素"。
- **水印模式更多样**：文字元素新增"平铺满图（防盗版水印）"和"单条对角线"两种模式，可调旋转角度、平铺间距；原来的"单个固定位置+拖拽"模式保留为默认。
- **图片排序**：左侧图片列表默认改成"自然排序"（第1箱、第2箱…第10箱，而不是字符串排序把"第10箱"排到"第2箱"前面），并提供"字符排序/修改时间/导入顺序"等切换选项。
- **水印库**：新增"★ 水印库"按钮，可以把当前排版存成一条记录（本机保存在 `~/.watermark_studio/library/`），随时浏览、一键套用或删除，区别于原来"保存/加载模板"要每次手动找文件。
- **图标元素拖拽缩放**：图标/色块元素选中后，预览图上会出现右下角小方块手柄，直接拖动即可缩放宽高，不用再手填数值框。

## 6. 后续可以扩展的方向

- 元素叠放层级调整（当前后添加的在最上层，`model.Template.move_z` 已经
  预留了接口，界面上加两个"上移/下移"按钮即可接上）。
- 文字对齐方式（居中/右对齐）、字间距、行距。
- 图标元素也支持画布上直接拖拽缩放（目前缩放走数值输入框，位置支持拖拽）。
- 多套模板管理面板（现在是加载/保存单个 json，够用但没有列表管理）。
